# CineMatch

CineMatch is a movie recommendation web application built with Python and Streamlit.

## Project Goal

Help users discover movies based on their preferences by asking:

- What genre are you in the mood for?
- Do you want something popular, highly rated, or underrated?

The application then recommends movies and explains why they were selected.

## Current Features

- Streamlit web interface
- Get Started workflow
- Genre selection
- MovieLens dataset integration
- Movie data displayed from MovieLens

## Dataset

This project uses the MovieLens Small Dataset.

Files currently used:
- `movies.csv`
- `ratings.csv`

MovieLens provides movie titles, genres, and user ratings which are used to generate recommendations.

## Tech Stack

- Python
- Streamlit
- Pandas
- MovieLens Small Dataset
